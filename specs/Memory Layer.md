# Purpose

The Memory Layer is responsible for remembering what is active, what has changed, what requires attention, and what should be surfaced at the appropriate time.

# Overview

Knowledge is timeless.
Memory is stateful.
The Memory Layer tracks active responsibilities and continuously adapts based on Marcos's behavior.

# Core Memory Objects

* Commitment
* Task
* Project
* Habit
* Recurring Responsibility
* Appointment
* Reminder
* Observation
* Lesson
* Pattern

# Commitment Lifecycle

A commitment may originate from:

* Marcos explicitly saying he will do something.
* Marcos asking Marcos OS to remember something.
* Sara requesting something.
* Marcos accepting an AI recommendation.

A commitment remains active until:

* Completed
* Cancelled
* Replaced

If overdue:

* Determine why.
* Suggest an alternative time.
* Break into smaller steps if appropriate.
* Learn from repeated behavior.
* Adapt future recommendations.

# Adaptive Behavior

The Memory Layer should:

* Detect repeated postponements.
* Change reminder strategy when necessary.
* Recommend better scheduling.
* Avoid repeatedly using strategies that are ineffective.
* Personalize future recommendations based on observed behavior.

# Learning Model

Every missed commitment, completed commitment, and behavioral trend should strengthen future recommendations.
The system should continuously improve instead of repeating ineffective behavior.
