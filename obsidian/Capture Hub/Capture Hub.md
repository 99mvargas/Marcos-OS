# Purpose

The Capture Hub is the universal intake system for Marcos OS.
Every idea, task, question, observation, reminder, voice memo, photo, email, or automation event enters Marcos OS through this system.

# Capture Philosophy

* Marcos should capture thoughts naturally.
* AI is responsible for organization.
* Preserve the original capture as the permanent source of truth.
* Create structured knowledge from the original capture.
* Marcos should never decide where information belongs.

# Capture Pipeline

1. Capture raw thought.
2. Preserve original wording.
3. Analyze intent.
4. Determine whether additional context is needed.
5. If needed, ask clarifying questions.
6. Adopt the appropriate expert role(s).
7. Generate recommendations.
8. Create structured knowledge.
9. Link related knowledge.
10. Present recommendations before creating long-term commitments.

# AI Responsibilities

* Classify information.
* Detect ambiguity.
* Ask only questions that materially improve the outcome.
* Select the appropriate domain experts.
* Reduce Marcos's cognitive load.
* Continuously improve the knowledge graph.

# Confidence Model

## High Confidence

* Automatically organize.

## Medium Confidence

* Organize.
* Flag for later review.

## Low Confidence

* Preserve in Capture Hub.
* Request clarification.

# Clarification Strategy

Do not immediately classify incomplete thoughts.
When additional context would significantly improve recommendations, ask focused follow-up questions before storing structured knowledge.

# Knowledge Output

Every capture may create or update:

* Facts
* Patterns
* Principles
* Lessons
* Projects
* Tasks
* Knowledge Objects

# Marcos OS Principles

* Preserve the raw capture.
* Organization is AI's responsibility.
* Curiosity before classification.
* Ask better questions instead of making assumptions.
* Every recommendation should reduce mental load.
* Every interaction should strengthen the knowledge graph.
